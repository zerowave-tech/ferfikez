# Férfikéz egy órára — редизайн

Одностраничный прототип редизайна сайта [ferfikezegyorara.hu](https://ferfikezegyorara.hu)
(венгерский сервис «мастер на час»). Собран как `.dc.html` — страница на
dc-рантайме с шаблонами `{{ }}`, `<sc-if>` / `<sc-for>` и веб-компонентом
`<image-slot>`.

## Структура

```
.
├── Ferfikez Redesign.dc.html   # страница — единственная точка входа
├── support.js                  # dc-рантайм (сгенерирован, не править вручную)
├── image-slot.js               # компонент <image-slot> (копия стартера)
├── .image-slots.state.json     # sidecar: картинки, вставленные в слоты
├── vercel.json                 # rewrite / → страница (см. «Деплой»)
├── assets/
│   ├── images/                 # фото и логотип, используемые страницей
│   │   ├── hero-tools.jpg
│   │   └── logo-mark.png
│   ├── icons/                  # контурные иконки-инструменты (декор секций)
│   │   ├── line-hammer.png
│   │   ├── line-saw.png
│   │   └── line-screwdriver.png
│   └── source/                 # исходники и заготовки, на странице не используются
│       ├── tools-outline*.png  # большие контуры, из которых вырезаны иконки
│       ├── tool-*.png          # отдельные вырезанные инструменты
│       └── src-*.jpg|webp      # оригиналы под hero и иконки
├── docs/
│   └── screenshots/            # скриншоты итераций и проверок вёрстки
└── uploads/                    # инбокс загрузок хоста (в git не попадает)
```

## Почему часть файлов лежит в корне

Это не беспорядок, а контракт рантайма — их нельзя раскладывать по папкам:

- **`.image-slots.state.json`** должен быть **соседом** HTML-файла: компонент
  читает его относительно документа, а хост пишет в директорию превью. Все
  страницы одной папки делят один sidecar, поэтому `id` слотов должны быть
  уникальны.
- **`support.js`** и **`image-slot.js`** хост кладёт рядом со страницей и
  перезаписывает при пересборке рантайма / повторном копировании стартера.
  Если унести их в `vendor/`, следующая генерация создаст новые копии в корне,
  а страница останется на устаревших.

Всё остальное — обычные ассеты, они и разложены по `assets/`.

## Как открыть

Достаточно открыть файл в браузере:

```bash
start "Ferfikez Redesign.dc.html"
```

Хост-превью не обязателен: `support.js` сам подгружает React 18.3.1, ReactDOM и
Babel standalone с `unpkg.com` (с SRI-хешами), поэтому шаблоны и `<image-slot>`
работают и из `file://`, и со статики. Единственное требование — доступ в
интернет у клиента.

## Деплой

Статический хостинг, сборка не нужна — заливается папка как есть.

Единственная тонкость: **`index.html` в проекте нет** (страница обязана
называться `*.dc.html`), поэтому корень сайта сам по себе отдаёт `404:
NOT_FOUND`. За это отвечает `vercel.json`:

```json
{ "rewrites": [{ "source": "/", "destination": "/Ferfikez%20Redesign.dc.html" }] }
```

Rewrite (а не redirect) — чтобы URL остался чистым `/`. Относительные пути
ассетов при этом резолвятся корректно: страница лежит в корне, значит
`./assets/images/…` → `/assets/images/…` и при запросе `/`, и при запросе файла
напрямую.

Если на других хостингах корень снова отдаст 404 — там нужен свой аналог
rewrite (Netlify: `_redirects` со строкой `/  /Ferfikez%20Redesign.dc.html  200`),
либо переименование страницы в `index.html`.

## Разделы страницы

Роутинг — через `<sc-if>` по флагам: `isHome`, `isServices`, `isPrices`,
`isRefs`, `isPartners`, `isTeam`, `isBlog`, `isContact`. Услуги разбиты на три
группы: *Házon belül*, *Kerti munkák*, *Autós munkák*.

## Работа с ассетами

- Фото контента (кейсы, блог, карта) берутся **удалённо** с
  `ferfikezegyorara.hu/wp-content/uploads/...` — локально не дублируются.
- Локальные пути в разметке — всегда относительные, вида
  `./assets/images/…`. При переносе файлов правьте `src` в HTML.
- Картинки в `<image-slot>` хранятся не файлами, а base64 внутри
  `.image-slots.state.json` — не удаляйте его, иначе слоты опустеют.
