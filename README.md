# Férfikéz egy órára — редизайн

Прототип редизайна сайта [ferfikezegyorara.hu](https://ferfikezegyorara.hu)
(венгерский сервис «мастер на час»). Две самостоятельные страницы — десктопная
и мобильная — собраны как `.dc.html` на dc-рантайме с шаблонами `{{ }}`,
`<sc-if>` / `<sc-for>` и веб-компонентом `<image-slot>`.

## Структура

```
.
├── Ferfikez Redesign.dc.html   # десктопная страница
├── Ferfikez Mobile.dc.html     # мобильная страница (см. «Две версии»)
├── support.js                  # dc-рантайм (сгенерирован, не править вручную)
├── image-slot.js               # компонент <image-slot> (копия стартера)
├── .image-slots.state.json     # sidecar: картинки, вставленные в слоты
├── vercel.json                 # маршруты / → нужная версия (см. «Деплой»)
├── assets/
│   ├── images/                 # фото и логотип, используемые страницей
│   │   ├── hero-tools.jpg
│   │   └── logo-mark.png
│   ├── js/
│   │   └── scroll-reveal.js    # анимация появления блоков при скролле
│   ├── icons/                  # контурные иконки-инструменты (декор секций)
│   │   ├── line-hammer.png
│   │   ├── line-saw.png
│   │   └── line-screwdriver.png
│   └── source/                 # исходники и заготовки, на странице не используются
│       ├── tools-outline*.png  # большие контуры, из которых вырезаны иконки
│       ├── tool-*.png          # отдельные вырезанные инструменты
│       └── src-*.jpg|webp      # оригиналы под hero и иконки
├── docs/
│   ├── scroll-reveal.md        # как устроена и подключена scroll-анимация
│   └── screenshots/            # скриншоты итераций и проверок вёрстки
└── uploads/                    # инбокс загрузок хоста (в git не попадает)
```

## Почему часть файлов лежит в корне

Это не беспорядок, а контракт рантайма — их нельзя раскладывать по папкам:

- **`.image-slots.state.json`** должен быть **соседом** HTML-файла: компонент
  читает его относительно документа, а хост пишет в директорию превью. Все
  страницы одной папки делят один sidecar, поэтому `id` слотов должны быть
  уникальны.
- **`support.js`** и **`image-slot.js`** хост кладёт рядом со страницей и
  перезаписывает при пересборке рантайма / повторном копировании стартера.
  Если унести их в `vendor/`, следующая генерация создаст новые копии в корне,
  а страница останется на устаревших.

Всё остальное — обычные ассеты, они и разложены по `assets/`.

## Две версии

Десктопная и мобильная — **не одна адаптивная страница, а две разные вёрстки**,
каждая со своим `.dc.html` и своим dc-скриптом:

| | Десктоп | Мобильная |
|---|---|---|
| Файл | `Ferfikez Redesign.dc.html` | `Ferfikez Mobile.dc.html` |
| Ширина макета | до 1320px | до 520px, по центру |
| Навигация | горизонтальная строка в шапке | бургер-меню + фиксированная нижняя панель «Hívás / Ajánlat» |
| `<image-slot>` | используется (4 слота) | не используется |
| Профиль анимации | `desktop` | `mobile` (см. «Анимации») |

Общее у них — `support.js`, ассеты в `assets/` и `assets/js/scroll-reveal.js`.
Разделы, тексты и дизайн-система совпадают, поэтому **правки контента нужно
вносить в обе страницы** — автоматической синхронизации между ними нет.

## Как открыть

Достаточно открыть файл в браузере:

```bash
start "Ferfikez Redesign.dc.html"
```

```bash
start "Ferfikez Mobile.dc.html"
```

Хост-превью не обязателен: `support.js` сам подгружает React 18.3.1, ReactDOM и
Babel standalone с `unpkg.com` (с SRI-хешами), поэтому шаблоны и `<image-slot>`
работают и из `file://`, и со статики. Единственное требование — доступ в
интернет у клиента.

## Деплой

Статический хостинг, сборка не нужна — заливается папка как есть.

Первая тонкость: **`index.html` в проекте нет** (страницы обязаны называться
`*.dc.html`), поэтому корень сайта сам по себе отдаёт `404: NOT_FOUND`.

Вторая: версий две, и на `/` нужно отдавать ту, что подходит устройству. Обе
задачи решает `vercel.json` — маршруты проверяются сверху вниз:

| Запрос | Отдаётся |
|---|---|
| `/` с мобильного User-Agent (`Android`, `iPhone`, `iPod`, `Mobile`) | `Ferfikez Mobile.dc.html` |
| `/` со всех остальных | `Ferfikez Redesign.dc.html` |
| `/mobile` | `Ferfikez Mobile.dc.html` |
| `/desktop` | `Ferfikez Redesign.dc.html` |

`/mobile` и `/desktop` — принудительные ссылки: посмотреть мобильную вёрстку
с компьютера и наоборот, не подделывая User-Agent.

Везде rewrite, а не redirect — чтобы URL оставался чистым `/`. Относительные
пути ассетов при этом резолвятся корректно: страницы лежат в корне, значит
`./assets/images/…` → `/assets/images/…` и при запросе `/`, и при запросе файла
напрямую.

На других хостингах нужен свой аналог. Netlify — `_redirects`, где условие по
устройству пишется отдельной строкой:

```
/   /Ferfikez%20Mobile.dc.html    200!  User-Agent=*Mobile*
/   /Ferfikez%20Redesign.dc.html  200
```

Если разбор User-Agent недоступен, минимум — отдавать десктопную версию на `/`,
а на мобильную вести ссылкой.

## Разделы страницы

Роутинг — через `<sc-if>` по флагам: `isHome`, `isServices`, `isPrices`,
`isRefs`, `isPartners`, `isTeam`, `isBlog`, `isContact`. Одинаковый на обеих
страницах; на мобильной к состоянию добавлен `menuOpen` — оверлей бургер-меню.
Услуги разбиты на три группы: *Házon belül*, *Kerti munkák*, *Autós munkák*.

## Анимации

Блоки появляются при скролле (fade-up, де-зум картинок, маска-разворот у
`h1`/`h2`) — за это отвечает `assets/js/scroll-reveal.js`, подключённый в
`<helmet>` обеих страниц. Разметку целей скрипт делает сам по списку
селекторов, править HTML не нужно.

Файл один на две вёрстки, различия вынесены в профили. Мобильная страница
подключает его так:

```html
<script src="./assets/js/scroll-reveal.js" data-rv-profile="mobile" defer></script>
```

Подробности, параметры профилей и что менять при новых секциях —
[`docs/scroll-reveal.md`](docs/scroll-reveal.md).

## Работа с ассетами

- Фото контента (кейсы, блог, карта) берутся **удалённо** с
  `ferfikezegyorara.hu/wp-content/uploads/...` — локально не дублируются.
- Локальные пути в разметке — всегда относительные, вида
  `./assets/images/…`. При переносе файлов правьте `src` в HTML.
- Картинки в `<image-slot>` хранятся не файлами, а base64 внутри
  `.image-slots.state.json` — не удаляйте его, иначе слоты опустеют.
