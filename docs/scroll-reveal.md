# Scroll-reveal анимация

## Что это

Анимация появления блоков при скролле (в духе ekft.vercel.app): блоки
всплывают снизу с fade-in, картинки внутри них выезжают из лёгкого зума,
заголовки выползают вверх из-под clip-path-маски. Анимация не одноразовая —
при обратном скролле блоки прячутся и проигрываются заново.

## Где лежит

- `assets/js/scroll-reveal.js` — сам скрипт (vanilla JS, без зависимостей и сборки).
- Подключён в `<helmet>` страницы `Ferfikez Redesign.dc.html` рядом с `image-slot.js`:
  ```html
  <script src="./assets/js/scroll-reveal.js" defer></script>
  ```
  dc-рантайм переносит содержимое `<helmet>` в `<head>`, пересоздавая теги
  `<script>`, поэтому скрипт выполняется как обычный внешний скрипт страницы.

## Как работает разметка целей

Скрипт сам помечает элементы, менять HTML не нужно. Помечаются прямые потомки
контейнеров из списка селекторов в начале `setup()`:

| Селектор | Что покрывает на этой странице |
|---|---|
| `main > div` | обёртки подстраниц (услуги, цены, референции, блог, контакт…) |
| `section > div` | обёртки секций главной и CTA-полосы `+36 20 572 1788` |
| `footer > div` | колонки подвала и нижняя строка с копирайтом |

Плюс любые `h1`/`h2` получают маску-разворот.

Шапка (`header > div`) намеренно не анимируется: она `position: sticky` и
висит в вьюпорте постоянно.

Если появятся новые секции с другой обёрткой — правьте этот список селекторов.

## Отличия от исходного handoff-файла

Файл пришёл как framework-agnostic заготовка; под эту страницу в нём изменены
две вещи:

1. **Список селекторов** — убран `header + section` (на этой странице после
   шапки идёт `<main>`, совпадений нет), остальное совпало со структурой.
2. **Добавлен `MutationObserver`** — страница рендерится dc-рантаймом на React
   и перерисовывается при смене раздела (`setState({ page })`), вкладок услуг
   и фильтров блога. Наблюдатель до-размечает узлы, появившиеся после первого
   рендера. Следит только за `childList`, а скрипт правит `style` и
   `data-*`-атрибуты — зацикливания нет.

Ручной вызов `window.refreshScrollReveal()` тоже остался — на случай, если
контент вставят в обход React.

## Параметры анимации

- Старт: `opacity: 0; transform: translateY(26px)`, картинки внутри — `scale(1.06)`.
- Показ, когда верх элемента пересекает ~92% высоты вьюпорта: 0.8s на блок,
  1.2s на де-зум картинки, стагger ~70ms на соседний элемент (до 5).
- `h1`/`h2`: `clip-path: inset(0 0 100% 0)` → `inset(0 0 -12% 0)`, 0.95s.
- Скрытие обратно, когда элемент уходит ниже ~115% высоты вьюпорта.
- У самого низа страницы порог снимается, иначе подвал не успевает раскрыться.
- Easing везде `cubic-bezier(0.16,1,0.3,1)`.
